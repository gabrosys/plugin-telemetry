# Security policy

## Reporting a vulnerability

Report a vulnerability privately through GitHub: open the repository's Security tab and choose "Report a vulnerability". Do not open a public issue or pull request for it.

Include the plugin version or commit, the CloudNativePG and Kubernetes versions, and the steps that show the problem.

## What the plugin does and what stays open

[docs/security.md](docs/security.md) describes what the plugin writes, the rights it holds, the admission policies that limit it, and the risks it does not cover.
